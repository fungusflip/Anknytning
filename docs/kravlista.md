# Kravlista – Anknytning

Persona: Nils, 21. Prioriterat enligt MoSCoW.

## Must have
1. Som Nils vill jag se event nära mig (Stockholm–Bro), så att jag hittar något utan att behöva leta.
2. Som Nils vill jag swipea mellan event, så att det går snabbt och enkelt att välja.
3. Som Nils vill jag använda appen utan att logga in, så att jag kan börja direkt.
4. Som Nils vill jag söka med intresseord, så att jag hittar event där vibben passar mig.
5. Som Nils vill jag se pris, tid och plats direkt, så att planen inte faller på praktiska saker.
6. Som Nils vill jag se vädret vid utomhusevent, så att jag vet om det blir av och vad jag ska ha på mig.

## Should have
7. Som Nils vill jag kunna logga in om jag vill, så att mina sparade event finns kvar.
8. Som Nils vill jag se vilka vänner som går, så att jag slipper gå själv.
9. Som Nils vill jag dela ett event med en kompis, så att vi kan gå tillsammans.
10. Som Nils vill jag se en "Kom ensam"-märkning, så att jag vet att det är okej att komma utan sällskap.
11. Som Nils vill jag få en påminnelse, så att jag inte glömmer eventet.

## Could have
12. Som Nils vill jag filtrera på ålder, så att jag hamnar bland folk i min ålder.
13. Som Nils vill jag köpa biljett direkt i appen, så att jag inte tappar bort det.
14. Som Nils vill jag hitta "testa på"-event, så att jag kan prova något nytt utan krav.

## Won't have (den här gången)
15. Som Nils vill jag chatta i appen. Bortvalt: chatt finns redan i andra appar.
16. Som Nils vill jag skapa egna event. Bortvalt: det löser inte problemet att hitta event.
17. Som Nils vill jag ha allt på ett ställe i stället för Orbi. Bortvalt: vi kompletterar, vi ersätter inte.
18. Som Nils vill jag läsa recensioner av event. Bortvalt: det löser inte huvudproblemet.

## Acceptanskriterier

**Story 1 – Event nära mig**
- Appen visar event mellan Stockholm och Bro.
- Vid 0 träffar visas det närmaste eventet.

**Story 2 – Swipea**
- Höger = intresserad, vänster = nästa.
- Ett event nås på högst 3 tryck.

**Story 5 – Pris, tid och plats**
- Syns på kortet utan extern länk.
- Gratis event är märkta "Gratis".
